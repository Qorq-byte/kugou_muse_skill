# 🎵 Kugou Music Downloader Skill

让 AI Agent 能够理解用户的自然语言音乐需求，并将其转化为可执行的酷狗音乐检索与合法下载流程。

> **核心理念：先理解音乐，再搜索；先判断下载权限，再执行下载。**

## ✨ 功能

这个 Skill 面向支持 Agent Skills 的 AI Agent，主要解决“我想听什么”到“找到并整理音乐”的完整流程。

### 🎧 自然语言音乐需求理解

用户不需要使用固定格式描述音乐，可以直接说：

> “帮我找一些适合凌晨一个人在城市里走路听的歌。”

> “我想听类似 The Weeknd 的电子 R&B，但节奏慢一点。”

> “找 20 首适合学习的日语歌，不要太吵。”

Agent 会自动提取：

* 音乐类型（Genre）
* 情绪（Mood）
* 场景（Scene）
* 语言（Language）
* 艺人及相似艺人（Artist）
* 年代（Era）
* 节奏（Tempo）
* 能量等级（Energy）
* 人声/纯音乐偏好
* 用户数量需求
* 是否要求下载

---

## 🔎 智能搜索

Skill 会把自然语言需求转换为适合音乐平台检索的关键词，并通过多组关键词寻找候选歌曲。

例如：

```text
用户：
“想听一些凌晨两三点，独自走在城市街头的音乐，
最好有电子和 R&B 的感觉。”

↓

分析：
Mood:
- lonely
- melancholic
- introspective

Scene:
- late night
- city
- walking alone

Genre:
- alternative R&B
- electronic
- downtempo
- dream pop

↓

搜索：
alternative R&B 夜晚
dark electronic R&B
late night city music
downtempo R&B
```

相比简单的关键词搜索，这种方式可以更准确地理解用户真正想要的音乐氛围。

---

## 🎯 音乐匹配排序

Skill 会综合多个维度对搜索结果进行排序，而不是简单按照播放量推荐。

默认考虑：

| 维度        |  权重 |
| --------- | --: |
| 音乐类型匹配    | 25% |
| 情绪匹配      | 20% |
| 艺人/相似艺人匹配 | 20% |
| 场景匹配      | 10% |
| 语言匹配      | 10% |
| 年代匹配      |  5% |
| 热度        |  5% |
| 用户额外限制    |  5% |

这样可以减少“热门但完全不符合用户口味”的结果。

---

## 🔄 参考歌曲相似推荐

用户可以直接提供一首歌曲作为参考：

> “找一些和这首歌感觉类似的。”

Agent 会根据歌曲的音乐特征进行匹配，例如：

* Genre
* BPM / Tempo
* Mood
* 编曲特点
* 乐器
* 人声特征
* 制作风格
* 能量等级

而不是简单返回同一个艺人的歌曲列表。

---

## 📥 酷狗音乐下载

当用户明确提出下载需求时，Skill 会继续执行下载流程：

```text
用户音乐需求
      ↓
音乐风格分析
      ↓
生成搜索关键词
      ↓
搜索酷狗
      ↓
获得候选歌曲
      ↓
匹配度排序
      ↓
检查下载权限
      ↓
合法可下载？
   ↙          ↘
 是            否
 ↓             ↓
下载        提供官方页面
 ↓
校验
 ↓
整理文件
```

### 下载安全原则

本 Skill **不会绕过音乐平台的版权、会员或技术限制**。

只允许在以下情况下执行下载：

* 平台官方允许下载；
* 用户已经拥有对应下载权限；
* 用户拥有音乐作品的相关权利；
* 音频明确属于公共领域或开放许可；
* 官方接口明确提供合法下载能力。

不会执行：

* 破解 DRM；
* 绕过会员限制；
* 绕过登录或权限验证；
* 抓取隐藏下载地址；
* 使用盗版来源替代官方来源。

## 📁 自动整理音乐

下载成功后，可以按照统一规则保存：

```text
Music/
├── Artist/
│   └── Album/
│       ├── 01 - Song A.mp3
│       ├── 02 - Song B.mp3
│       └── 03 - Song C.mp3
```

默认文件名：

```text
Artist - Song Title.ext
```

例如：

```text
The Weeknd - Blinding Lights.mp3
```

同时会进行歌曲去重，避免重复下载相同内容。

例如：

降低：

```

```

Agent 不需要重新从零开始搜索，而是基于当前结果继续调整。

## 💬 使用示例

### 示例 1：学习音乐

```text
帮我找一些适合学习的时候听的日语歌，
不要太吵，最好有一点 Lo-fi 感。
```

Agent 会根据：

```text
Language = Japanese
Scene = Study
Energy = Low
Genre = Lo-fi / J-Pop / Ambient
```

进行搜索和筛选。

---

### 示例 2：夜晚城市氛围

```text
我要一些凌晨在城市里走路听的音乐，
有一点孤独感，电子 + R&B，
类似 The Weeknd。
```

Skill 会将需求转换为多维音乐特征，然后寻找匹配歌曲。

---

### 示例 3：批量下载

```text
找 30 首适合晚上开车听的电子音乐，
然后下载。
```

流程：

```text
搜索
→ 去重
→ 匹配排序
→ 下载权限检查
→ 下载合法可下载歌曲
→ 自动整理
```

如果只有部分歌曲拥有可确认的合法下载权限，则只下载这些歌曲。

## 🤖 Agent 兼容性

Skill 按通用 Agent Skill 思路设计，可作为以下环境的基础：

* Claude Code
* Codex
* ChatGPT Agent
* 其他支持 `SKILL.md` / Agent Skills 的 Agent 框架

不同 Agent 对工具调用、浏览器自动化和本地文件系统的权限模型不同，因此：

> **Skill 负责音乐理解、搜索策略、排序逻辑和下载规则；实际的酷狗访问与文件下载能力由 Agent 所拥有的工具提供。**

---

## 🛠️ 工具要求

为了实现完整的“搜索 → 下载 → 保存”自动化，Agent 通常需要具备：

```text
Browser / Web Access
        +
File System Access
        +
Music Search
        +
Download Capability
```

如果 Agent 只能进行文本对话而没有浏览器或文件系统工具，则仍然可以执行：

```text
音乐需求理解
        ↓
关键词生成
        ↓
歌曲推荐
        ↓
匹配排序
```

但不能自动把歌曲保存到本地。
